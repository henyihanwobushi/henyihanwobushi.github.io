Nowadays, with the rise of data lakes, there are many tools that can help us to create a incremental table which support update and delete without re-ingesting the whole data.

Here are some of them:
- [Delta Lake](https://delta.io/)
- [Iceberg](https://iceberg.apache.org/)
- [Hudi](https://hudi.apache.org/)
- [Paimon](https://paimon.apache.org/)
