Data Lake is a concept of storing data in a raw format, and then process it when needed. It is a place to store all kinds of data, including structured, semi-structured, and unstructured data.

## Data Lake vs Data Swamp

Data Swamp is a concept of storing data in a raw format, and then process it when needed. It is a place to store all kinds of  data, including structured, semi-structured, and unstructured data. Compared to Data Swamp, Data Lake has a governance layer to ensure the data quality.

## Data Lake vs Data Warehouse

Data Warehouse is a concept of storing data in a processed format, and manage it in a structured way.
