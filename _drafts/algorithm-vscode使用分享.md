# 前言

工欲善其事，必先利其器。

个人接触过的编辑器有Nano、Vim、Atom、NetBeans、Visual Studio、Eclipse、Sublime Text、IntelliJ IDEA家族，后续逐渐稳定下来，留下了三款常用编辑器：
- Vim：Linux自带编辑器，优秀的编辑模式，支持扩展，灵活配置
- IntelliJ Idea：Java开发者最喜爱的编辑器，支持各种语言，插件丰富，功能强大
- VSCode：功能强大，支持各种语言，插件丰富，非常适合开发者使用

三款编辑器分别应对不同的需求，Vim适合在命令行中进行简短的编辑，速度快，响应好，简单高效；IntelliJ Idea适合在IDE中进行复杂的编辑，功能丰富，速度慢，响应慢，功能强大；VSCode配合各种插件则是瑞士军刀一样的存在，支持了Java以外其他编程语音开发以及日常文本编辑工作。

## 1. 安装

VSCode是微软推出的免费的跨平台代码编辑器，支持Windows、Mac和Linux。

下载地址：https://code.visualstudio.com/download

## 2. 使用

VSCode使用文档：https://code.visualstudio.com/docs

官方文档中内容比较丰富详实，但VSCode的可配置、可扩展性非常之强，尤其是各种快捷键的配置，有时间折腾的话几乎可以改造成任何你想要的样子，而且VSCode自带的功能以及插件几乎可以大部分人的需求。

使用编辑器其实是比较简单的，可以双击应用图标打开，也可以文件右键编辑，或者可以在命令行里通过`code`命令打开。

VSCode是一个非常强大的编辑器，几乎可以说是一款适合于任何编程语言及文本编辑的IDE。

### 2.1 基础快捷键

VSCode的快捷键非常之多，这里列举一些常用的默认快捷键，具体快捷键可以查看官方文档，并改成自己更喜好的快捷键。

| 快捷键          | 功能                               |
| --------------- | ---------------------------------- |
| CMD + P         | 打开文件搜索，快速在多个文件中跳转 |
| CMD + Shift + P | 打开命令面板，快速检索功能及命令   |
| CMD + ,         | 打开设置                           |
| CMD + K CMD + S | 打开代码快捷方式配置页面           |

### 2.2 基础功能

#### 文本编辑

作为一款编辑器，VSCode的编辑功能非常之强大，支持各种高级编辑功能：

| 功能       | 快捷键                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------- |
| 多行编辑   | 按下 Shift + Option + Arrow Keys（上/下/左/右）来扩展你的选择区域。                          |
| 多光标编辑 | 按住 Option 键，然后用鼠标左键点击你想要添加光标的位置。                                     |
| 代码补全   | 通过Language Server Provider补全代码，支持各种语言。                                         |
| 代码格式化 | 通过安装各语音的Linter插件可以方便的对各种语音源码进行格式化，包括json、xml、markdown、sql。 |
| 代码导航   | VSCode默认右侧有缩略图，左侧资源管理器中代码大纲，并且提供转到定义等功能                     |
| 代码高亮   | VSCode提供各种语音的插件，可以根据代码的不同语音进行语法高亮。                               |

#### 资源管理

VSCode的资源管理非常之强大，可以快速的在多个文件中跳转，并且可以快速的在项目中查找文件。支持各种文本类型的文件，并且支持各种插件，可以快速的在项目中管理文件。

#### 版本管理

VSCode继承了基础的版本管理组件，默认使用git进行版本管理，可以实现：分支管理、变更预览、代码提交、冲突解决等。

可以通过版本管理工具进行代码库甚至文档的版本管理以及多作者协作。

配合定时代码提交可以避免不小心关闭文档导致的文档代码丢失；而长期维护的文档也可以

#### 实时预览

VSCode除了进行代码编辑，通过插件也可以支持MarkDown、Latex、Plantuml、Mermaid等文档、绘图工具的实时预览。可以像编辑代码一样编辑文档，以及基础的插图，同时可以方便的迁移到语雀、钉文档等在线文档中。

### 2.3 插件

VSCode的插件非常之丰富，可以快速的进行各种开发工作，并且支持各种插件市场，可以很方便的安装各种插件。通过插件可以将VSCode打造成一款通用编辑器，适用场景非常之广，下面介绍几个我自己常用的插件。


#### 1. Copilot/通义智能助手

Copilot是一个代码提示插件，可以通过AI模型进行代码提示，可以快速的进行代码编写。除了代码提示，通过配置可以将支持的文档类型扩展到MarkDown、Latex等类型的文档，可以快速的进行文档编写。

通义智能助手是一个问答助手，可以在编辑器中直接进行问题的提问，提升工作效率。

目前在钉钉文档及各类文档中的智能助手多是基于用户的行为，但在VSCode的插件中会以自动补全的形式出现，助手会基于上下文自动进行文本补全，交互更加自然。

甚至可以达到仅梳理一下大纲，然后通过助手自动补全的形式进行文档的创作。大部分的描述性文本仅需要简单调整即可，调整可以实时进行，并实时生效及时影响助手的行文，可以大大提升文档的创作效率。

#### 2. Foam + Markdown All in One

Foam是一个基于VSCode的知识管理工具，可以基于MarkDown文档格式快速的进行文档的创作，可以将文档进行分层，并且支持各种插件，可以快速的进行文档的创作。

Markdown文档格式简单易懂，支持各种扩展，如：表格、公式、图片、链接等，可以快速的进行文档的创作。并且基于文本格式可以方便进行版本管理以及多人协作。

Foam提供各种功能，可以辅助构建个人知识库：

- 图视图：将文档展示为图（Graph），可以展示文档间联系并可以快速导航；
- 文档链接：可以通过```[[]]```形式在文档中引用其他文档；
- 链接预览：可以在链接上鼠标悬浮，可以对文档内容进行预览；
- TODO列表：可以展示文档中所有标记的TODO项，实现简单的任务管理。


#### 3. Jupyter

Jupyter是一个交互式笔记本，可以在浏览器中进行交互式编程，支持多种语言，包括Python、R、Julia等，可以快速的进行数据分析、机器学习等工作。

Jupyter的插件可以在VSCode中进行交互式编程，可以通过编辑器的基础功能，如：代码补全、代码格式化、代码导航等，可以极大的提升Jupyter的使用体验。Jupyter文档以.ipynb为后缀，可以方便的进行版本管理。


#### 4. Conda

Conda是一个Python包管理工具，可以方便的进行Python包的安装、卸载、更新等操作，可以方便的进行Python环境的管理。

Conda的命令行工具仅在环境管理的时候使用，使用频次导致每次都需要查看文档，通过VSCode的Conda插件可以方便的进行环境管理，提升使用效率。

#### 5. DevToys

DevToys是一个工具合集，可以平替工具网站，常用的功能包括：

- 各种编辑解码：Html、URL、Base64、Hash、数字进制转换
- 时间戳转换：Unix时间戳与日期时间戳互转
- 正则表达式：正则表达式测试工具

#### 6. Gist

Gist是一个代码片段管理工具，可以方便的管理代码片段，可以方便的进行分享，可以方便的进行版本管理。通过VSCode的Gist插件可以更方便的进行Gist的发布以及管理，可以提升分享及使用的效率。

#### 7. Plantuml

Plantuml是一个绘图工具，可以通过文本的形式绘制各种图形，包括：流程图、时序图、类图、组件图、状态图、对象图、部署图、用例图、活动图、构件图、甘特图、实体关系图等。

Plantuml的插件可以在VSCode中进行绘图，并支持实时预览、导出图片等功能，并且可以方便的进行版本管理。


#### 8. 自定义扩展

VSCode的扩展非常之丰富，除了可以从插件市场选择适当的插件之外，还可以方便的开发自己的插件，并且可以方便的发布到插件市场。

VSCode的插件开发基于TypeScript或者javascript，并且需要了解VSCode的API，有一定的入门门槛，但官方的文档和示例([Your First Extension](https://code.visualstudio.com/api/get-started/your-first-extension))非常友好，社区也有很多的教程，可以快速的上手自己的插件。
