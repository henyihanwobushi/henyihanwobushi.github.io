Before the question, let's discuss why we need architecture. Architecture is not only a term in software development, there are many other fields that need architecture, such as building, painting, music, etc.

# Why do we need architecture?

If there is one man, works on a small project, which do a one-time job, he can do it, even without knowing about architecture.

But, when the software grows, more people involved, including users and developers, more complex functions supported, longer time the project is maintained...

Then we will know some facts, we need more people to support the fast growth of the demmands.

- more develpers are needed,
- more limited time is needed,
- more changes are made.
